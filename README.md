# Blockwild — воксельная песочница на Three.js

Оригинальная игра в жанре «кубическая песочница / выживание»: бесконечный мир, биомы, пещеры, освещение, крафт, выживание, мобы, погода, сохранения.
Все названия, блоки, мобы, рецепты, текстуры и звуки собственные; **текстуры и звуки генерируются процедурно в коде** (внешних ассетов нет).
Работает на ПК (клавиатура + мышь) и на телефонах/планшетах (сенсорное управление).

## Запуск

```
start.bat                      # python -m http.server 8080 + открывает браузер
# или вручную:
python -m http.server 8080     # затем http://localhost:8080
```

`file://` не подходит (ES-модули и воркеры требуют HTTP). Three.js `0.160.0` лежит локально в `lib/three.module.js` — интернет не нужен.

**GitHub Pages**: игра — полностью статический сайт, все пути относительные (importmap `./lib/...`, воркеры через `new URL(..., import.meta.url)`), поэтому работает и из подкаталога `/blockwild/`. Сервер не нужен, сохранения — в IndexedDB браузера.

| Красться (не падать с края) | Shift |
| Бег | Ctrl или двойное нажатие W |
| Ломать / бить | ЛКМ (удерживать) |
| Поставить / использовать (верстак, печь, сундук, дверь, еда) | ПКМ |
| Выбрать блок (pick block) | СКМ |
| Хотбар | колесо мыши, 1–9 |
| Инвентарь | E |
| Выбросить предмет (Ctrl — весь стак) | Q |
| Чат / команды | T или `/` |
| Скрыть HUD / скриншот PNG / отладка / вид от 3-го лица | F1 / F2 / F3 / F5 |

В инвентаре: ЛКМ — взять/положить/обменять, ПКМ — половина стака / по одному, Shift+ЛКМ — быстро переместить, 1–9 над слотом — обмен с хотбаром, перетаскивание с зажатой кнопкой — распределение стака по слотам, клик вне окна — выбросить.

## Управление (телефон / планшет)

Схема одна и описана явно:

- **Левая часть экрана** — виртуальный джойстик (появляется там, где коснулись); до упора вперёд — бег.
- **Правая часть экрана** — перетаскивание: осмотр. **Короткое касание = поставить/использовать** блок под прицелом (прицел в центре экрана). **Касание с удержанием (≈0.3 с) = ломать блок / бить моба.**
- Кнопки: ⤒ прыжок (двойное нажатие в творческом режиме — полёт), ⤓ красться (фиксируемая; за рулём — выйти из машинки), 🎒 инвентарь, 💬 чат/команды, ⏸ пауза, ⛶ полный экран, 🤖 превращение машинки (видна рядом с ней). Хотбар — касание по слоту. Касание плашки миссии повторяет голосовое задание.
- Инвентарь без перетаскивания: касание — взять/положить стак, **двойное касание — быстро переместить**, кнопка «½ режим» — брать половину / класть по одному, «✕ Закрыть».
- Интерфейс масштабируется под экран, учитывает safe-area (вырезы), отключены зум, прокрутка, pull-to-refresh и контекстное меню долгого нажатия. В портретной ориентации показывается подсказка повернуть устройство.
- Мобильные значения по умолчанию: дальность 4 чанка, pixel ratio 1, меньше частиц, упрощённые облака (один слой, меньше ячеек); всё меняется в настройках.
- На iOS Safari полноэкранный режим недоступен (кнопка скрыта) — добавьте страницу на главный экран.

## Команды чата

## Для малышей: спасатели

Включается при создании мира («Городок и миссии спасателей», по умолчанию — да; в старых мирах тоже включено).

- **Питомцы.** Котята (Рыжик, Дымок, Снежок, Носочек) и щенки-спасатели в шапочках с рюкзачками (Огонёк, Дозор, Кирпичик) живут на лугах. Приручаются лакомством по ПКМ: котята — рыбка, курятина, яйцо; щенки — косточка-печенька (пшеница + кость), кость, мясо. Приручённый ходит следом, а если застрял или отстал — «прыгает» к игроку. ПКМ без лакомства — сесть/встать и сердечки. Питомцы неуязвимы. Яйца призыва «Котёнок» и «Щенок-спасатель» — в творческом инвентаре.
- **Машинка-робот.** Предмет «Машинка-робот» (крафт: 3 красной шерсти, железный слиток, 2 угля), ставится ПКМ. ПКМ по машинке — сесть (вид от 3-го лица), управление как при ходьбе, прыжок — подскок, сама заезжает на блок. R / 🤖 — превращение в робота: он ходит рядом и высоко прыгает, ПКМ — машет рукой. ПКМ шерстью (красная, синяя, жёлтая, зелёная) перекрашивает.
- **Городок спасателей.** Строится один раз на ровном месте недалеко от спавна и никогда не задевает чанки, которые игрок уже менял: башня с винтовой лестницей из полублоков (подниматься без прыжков) и смотровой кабиной, площадь с фонтаном и большой лапкой, 5 домиков, 3 будки со щенками, канал с мостом, машинка у башни, сундуки с лакомствами и цветной шерстью у входа. Пока место не прогружено, стрелка ведёт к нему, и городок появляется, когда игрок подходит.
- **Миссии.** Голосовое задание (озвучка `audio/*.mp3`, генерация `python tools/gen_audio.py`, тексты в `src/game/phrases.js`) → стрелка-компас в углу и звёздный маяк над целью → ⭐ за выполнение. Задания: дойти до башни, найти потерявшегося котёнка или щенка (достаточно обнять), снять котёнка с дерева, найти и принести угощение голодному питомцу, доехать до флажка (если есть машинка).

## Мир

- Чанк 16×16×256 (`Uint16Array` блоки + свет 4 бита солнце / 4 бита блок), дальность 4–16 (по умолчанию 8), загрузка по спирали с приоритетом по направлению взгляда.
- Рельеф: октавный simplex + кривые континентальности/эрозии/гребней, пещеры «сыр» + «спагетти», подземные озёра лавы ниже y=12, руды по глубине (уголь, медь, железо, золото, синевик), «базальтовое дно» на y=0–4.
- 10 биомов: океан, пляж, луга, берёзовая роща, хвойная тайга, пустыня, саванна, болото, заснеженная тундра, каменистые горы (цвет травы/листвы/воды плавно смешивается между биомами).
- Структуры: 5 видов деревьев (дуб + большой дуб, берёза, ель, акация, болотная ива), кактусы, тростник, цветы, трава/папоротник, валуны, каменные руины с сундуком-лутом.
- Жидкости растекаются (источники, уровни 1–7, падающие потоки, бесконечная вода из двух источников), вода+лава → булыжник / вулканическое стекло. Песок и гравий падают, листва опадает без бревна, саженцы вырастают в деревья, пшеница/тростник/кактусы растут по случайным тикам, трава распространяется.

## Рецепты (74)

- Доски ×4 из бревна (5 пород), палки ×4 (2 доски), верстак (2×2 досок), сундук (8 досок), печь (8 булыжников), факел ×4 (уголь/древесный уголь над палкой), дверь ×3 (2×3 доски), светокамень (2×2 факела).
- Инструменты (кирка `МММ/.П./.П.`, топор `ММ/МП/.П`, лопата `М/П/П`, меч `М/М/П`, мотыга `ММ/.П/.П`) из досок / булыжника / железного слитка / синевика.
- Броня (шлем `МММ/М.М`, нагрудник `М.М/МММ/МММ`, поножи `МММ/М.М/М.М`, сапоги `М.М/М.М`) из шкуры / железа / синевика.
- Хлеб (3 пшеницы в ряд), кирпичный блок (2×2 кирпичей), каменный кирпич ×4 (2×2 камня), песчаник (2×2 песка), стеклянные панели ×16 (2×3 стекла), пороховой бочонок (порох+песок «шашкой»), ножницы (2 железа по диагонали), огниво (железо + уголь), мшистый булыжник (булыжник + папоротник).
- Плиты ×6 (3 в ряд: дуб, ель, булыжник, каменный кирпич, песчаник, кирпич), лестницы ×4 (дуб, булыжник, каменный кирпич, песчаник).
- Блоки руд (9 слитков/угля/синевика → блок) и обратно (блок → 9).
- Переплавка в печи (10 с на предмет): булыжник→камень, песок→стекло, комок глины→кирпич, глина→кирпичи, руды→слитки, мясо→жареное, бревно→древесный уголь.

Полный список — в `src/game/recipes.js`.

## Выживание

Здоровье 20, голод 20 + насыщение, регенерация при сытости, кислород под водой, урон от падения/лавы/кактуса/мобов, броня, прочность инструментов, смерть с выпадением инвентаря и респауном. Еда: яблоки с листвы, хлеб, жареное мясо. Мотыга делает грядку, семена даёт трава. Пороховой бочонок поджигается огнивом (ПКМ) и взрывается с разрушением блоков; грибник-подрывник взрывается рядом с игроком.

Мобы: «рогатый баран» (стрижка ножницами → шерсть), «пятнистая курица» (яйца), «лесной кабан», «болотник» (ближний бой), «костяной лучник» (стрелы, горит на солнце), «грибник-подрывник». ИИ: блуждание, паника, преследование, A* по сетке на 16 блоков, прыжки через блок, отбрасывание, красная вспышка урона, дроп; спавн по свету и биому, деспавн вдали, лимит числа.

## Архитектура

```
index.html, style.css, start.bat, README.md, lib/three.module.js
src/
  main.js                    — точка входа
  core/      noise.js (simplex 2D/3D, PRNG, хеши), math.js, events.js
  world/     blocks.js (реестр блоков), world.js (чанки, пулы воркеров), generator.js, biomes.js,
             structures.js, lighting.js (BFS света), fluids.js, tick.js (случайные тики, опора, падение), shapes.js
  render/    textures.js (процедурный атлас 16×16 + мипмапы без «швов»), mesher.js, chunkRenderer.js (ShaderMaterial),
             sky.js, clouds.js, particles.js, weather.js, selection.js, hand.js, tilenames.js
  workers/   genWorker.js, meshWorker.js     — module workers: генерация и свет+меширование
  player/    player.js, physics.js (AABB по осям), controls.js, raycast.js (DDA)
  entity/    entity.js, mobs/ (mobs.js, spawner.js), ai.js (A*), mobmodel.js, models.js, items-drop.js, primed.js
  game/      game.js (цикл), items.js, recipes.js, crafting.js, furnace.js, inventory.js, survival.js,
             interaction.js, actions.js, commands.js
  ui/        hud.js, inventoryUI.js, menus.js, debug.js, chat.js, icons.js, touch.js
  audio/     sfx.js (WebAudio-синтез), ambience.js (музыка, пещеры, ветер/дождь)
  save/      storage.js (IndexedDB, RLE)
```

Ключевые решения: мешер в воркере работает по региону 3×3 чанка — внутри него считается BFS-освещение (солнце + блочный свет, 15 уровней) и строится меш с **per-vertex AO**, **гладким освещением** и флипом квадов; три слоя (opaque / cutout / translucent); вершины — `Int16` позиции и `Uint8` атрибуты; единый `ShaderMaterial` (свет = max(солнце·день, блок с тёплым оттенком), туман под цвет неба, подводный туман, качание листвы/травы, анимация воды и лавы); при установке/ломании блока пересчитываются изменённый и затронутые соседние чанки.

## Сохранения

IndexedDB: метаданные мира, игрок, инвентарь, время, погода, **только изменённые чанки** (RLE), содержимое сундуков/печей, мобы. Автосейв каждые 30 с, при паузе, при сворачивании вкладки и выходе.

## Упрощения / известные ограничения

- Освещение при правке блока пересчитывается заново по региону 3×3 чанка в воркере (а не инкрементальной BFS на главном потоке); соседи перестраиваются только в зоне влияния света.
- Факел ставится только на верхнюю грань блока (без настенных вариантов); лестницы/полублоки без AO.
- Прозрачные слои сортируются по чанкам, внутри чанка порядок фиксирован.
- Мобы без размножения; у лучника нет собственного лука-предмета для игрока; нет опыта, зачарований и кроватей.
- Хэндлинг мобильных браузеров проверялся эмуляцией (Playwright: iPhone 13, Pixel 7), на реальных устройствах возможны отличия по производительности.
- Звуки синтезируются WebAudio — тембр отличается от «записанных» игровых звуков.
